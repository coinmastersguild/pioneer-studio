# Community code of conduct

We want Pioneer Studio to be a practical, welcoming place to build. Be respectful,
specific, and constructive. Critique ideas and code rather than people. Do not
harass, threaten, discriminate against, impersonate, or expose private information
about another participant.

Project maintainers may edit or remove contributions and restrict participation
when behavior harms the community or the project. Report conduct concerns
privately to the repository maintainers through GitHub rather than escalating them
in a public thread. Maintainers will review reports in good faith and protect the
reporter's privacy as far as reasonably possible.
